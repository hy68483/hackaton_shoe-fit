# ShoeFit Frontend

Mobile web frontend for the ShoeFit AI shoe size recommendation project.

## Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router

## Setup

```powershell
npm install
```

Copy local environment settings:

```powershell
copy .env.example .env
```

## Run

```powershell
npm run dev
```

Default URL:

```text
http://127.0.0.1:5173
```

## Build

```powershell
npm run build
```
