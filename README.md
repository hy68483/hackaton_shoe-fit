# hackaton_shoe-fit

AI와 OpenCV를 활용해 사용자의 발 치수를 측정하고, 신발 모델별 맞춤
사이즈를 추천하는 모바일 웹 쇼핑몰 프로젝트입니다.

## 서비스 구조

```text
React (Vercel)
    -> HTTPS
Nginx (AWS EC2)
    -> FastAPI
    -> PostgreSQL
    -> SAM + OpenCV 발 측정 파이프라인
```

백엔드는 Nginx, FastAPI, PostgreSQL을 Docker Compose로 운영하며,
Let's Encrypt 인증서로 HTTPS를 제공합니다.

## 부하 테스트 기준선

한국에서 시드니 리전 EC2의 배포 API를 대상으로 Locust 2.47.0을
실행했습니다. 각 가상 사용자는 한 번 로그인한 뒤 0.5~1.5초 간격으로
상품 40%, 사용자 정보 30%, 브랜드 20%, 헬스 체크 10% 비율의 조회
요청을 반복했습니다. 사용자는 초당 1명씩 증가했고 각 구간은 3분간
독립적으로 실행했습니다.

| 동시 사용자 | 실행 시간 | 요청 수 | 실패 | 처리량 | 평균 응답 | p95 |
|---:|---:|---:|---:|---:|---:|---:|
| 5명 | 3분 | 725 | 0 | 4.05 req/s | 237 ms | 240 ms |
| 10명 | 3분 | 1,417 | 0 | 7.89 req/s | 243 ms | 250 ms |
| 20명 | 3분 | 2,757 | 0 | 15.34 req/s | 242 ms | 240 ms |

20명 테스트에서 백엔드의 관측 최대 CPU는 5.50%, 메모리는 77.59 MiB였고,
5xx 오류, traceback, OOM은 발생하지 않았습니다. 일반 조회 요청의
중앙값은 약 230~240 ms였고 비밀번호 해싱을 포함한 로그인은 20명
구간에서 평균 958 ms였습니다.

이 결과는 최대 처리 용량이 아니라 초기 기준선입니다. 상품과 브랜드
데이터가 비어 있었고 각 단계가 3분으로 짧았으며, SAM/OpenCV 이미지
분석 부하는 제외했습니다. 다음 단계는 실제 데이터 기반 10분 이상
지속 테스트와 AI 분석 동시 사용자 1명, 2명, 3명 테스트입니다.
